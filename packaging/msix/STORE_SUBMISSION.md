# NewScid — Microsoft Store Submission Guide

## 1. Monetization Model (Free Edition + $9.99 Permanent Unlock)
NewScid is configured for the Microsoft Store as a **Free** base app with a **$9.99 one-time Durable Add-on**:
- **Free Store Edition (without the add-on):** All features are usable, and the non-obligatory support reminder appears on startup (once per 24 hours when dismissed).
- **$9.99 Permanent Unlock Add-on (`newscid_pro_permanent`):** Verified at runtime via WinRT `Windows.Services.Store.StoreContext.GetAppLicenseAsync()` + `AppxPackage.SignatureKind == Store`. Once purchased, startup reminders are permanently disabled (`IsStorePurchase = true`, `IsLifetime = true`).
- **Compiled / Non-Store Windows `.exe`:** `GetCurrentPackageFullName` returns `APPMODEL_ERROR_NO_PACKAGE`, so standalone compiled binaries keep the normal voluntary Stripe support prompt intact.

## 2. Partner Center Setup
1. Create a new app reservation in **Microsoft Partner Center** (`NewScid Chess Database`).
2. Copy your **Package/Identity/Name** and **Package/Identity/Publisher** (`CN=...`) into `packaging/msix/AppxManifest.xml` (or pass `-Publisher` to `build-msix.ps1`).
3. Under **Add-ons**, create a **Durable** add-on:
   - **Product ID / In-App Offer Token:** `newscid_pro_permanent`
   - **Price:** `$9.99 USD`
   - **Content type:** Digital license (never expires)
4. Copy the generated **12-character Store ID** (e.g. `9NXXXXXXXXXX`) and pass it to `build-msix.ps1 -AddOnStoreId 9NXXXXXXXXXX`.

## 3. Building the MSIX
On a Windows 10/11 build machine with Windows SDK (`makeappx.exe`), Go 1.24+, and Node.js 20+:
```powershell
.\packaging\msix\build-msix.ps1 `
  -AddOnStoreId "9NXXXXXXXXXX" `
  -Version "1.3.45.0" `
  -Publisher "CN=YOUR-PARTNER-CENTER-ID"
```
Optional: pass `-BundledStockfishPath C:\path\to\stockfish.exe` to bundle GPLv3 Stockfish directly inside the MSIX (Store policy forbids downloading `.exe` binaries at runtime, whereas bundling GPLv3 Stockfish inside the MSIX is permitted).
